# 企业级 CAPA 关闭治理

上海如静知华信息科技有限公司（[知华科技](https://www.zhuatech.cn/)）将根因、整改、有效性验证、风险与关闭审批组成符合企业审计要求的 CAPA 闭环。

- 验证根因、措施完成度、观察窗口、样本量和是否复发。
- 流程变更同步文件与培训，并重新评估残余风险。
- CAPA 责任人与 QA 审批人独立，关联 NCR、审核和客诉必须关闭。
- 逾期自动升级；高残余风险或复发强制重新打开。

接口：`POST /api/enterprise/qms/capa-closure`，返回 `CLOSE / REVIEW / REOPEN`、风险和审批路径。
