# QMS 企业质量闭环说明

上海如静知华信息科技有限公司 · [知华科技官网](https://www.zhuatech.cn/)

企业深化版本增加检验方案、抽样检验单、不合格项和 CAPA 的真实状态机。检验方案配置 AQL 与接收数，启用后才能建检验单；抽样数不得超过批量，不良数不得超过抽样数；系统依据接收数自动判定合格或不合格，不合格时自动生成 NCR。

NCR 支持返工、报废、退货、让步接收和进入 CAPA。严重缺陷禁止让步接收并强制进入 CAPA。CAPA 包含根因、纠正措施、预防措施和证据摘要，经质量管理员验证有效后同时关闭 CAPA 与 NCR。

验收覆盖失败检验到 CAPA 关闭、合格检验不产生 NCR、严重不合格禁止让步接收。该版本是企业质量系统二次开发基线，正式生产还应接入量具、实验室数据、电子签名、法规验证和审计归档策略。
